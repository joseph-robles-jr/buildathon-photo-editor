This is a simple photo editor that handles exposure adjustments, RGB level changes, and a simple crop.
## Build
From the root of the project, run:
```bash
mvn install
mvn compile
mvn javafx:run
```
or (Prefered)
```bash
mvn install
mvn package
java -jar target/buildathon-1.0-SNAPSHOT.jar
```
